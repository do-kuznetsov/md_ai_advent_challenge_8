## Рекомендации по использованию

- Для базового запуска использовать один общий запрос с короткой инструкцией и `qwen3:8b-q4_K_M`.
- Для оптимизированного запуска использовать строгий prompt, JSON Schema и низкую температуру на стадии фактологического анализа.
- Для проверки влияния квантования запускать одинаковый prompt и одинаковые параметры на `qwen3:8b-q4_K_M`, `qwen3:8b-q8_0`, `qwen3:8b-fp16`.
- Для проверки длинного контекста смотреть, находит ли модель поздние документы `R-193...R-200`, особенно уточнение по версии 3.2 и факт `R-199`.
- Для проверки качества считать точность категорий, ошибку по количеству упоминаний, число неподтверждённых утверждений и корректность обработки контрольных фрагментов.
